# Project 05 — Cloud Monitoring & Alerting

## Overview
This project demonstrates infrastructure provisioning and CPU monitoring using Terraform and Huawei Cloud.

## Technologies
- Terraform
- Huawei Cloud ECS
- Huawei Cloud Cloud Eye (CES)
- VPC, Subnet, Security Group, and EIP
- Ubuntu 24.04 LTS

## Lab Results
- Successfully deployed an ECS using Terraform.
- Created a CPU utilization alarm with a 70% threshold.
- Performed a CPU stress test.
- Alarm triggering was not conclusively verified.
- Successfully destroyed all 10 Terraform-managed resources.
